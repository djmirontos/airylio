# Public Assets

This directory contains public assets for the Airylio landing page.

## Favicon
- **favicon.ico** - Replace with actual 32x32 or 64x64 favicon in ICO format
  - Recommended: Use the Airylio app icon
  - Format: ICO with favicon size (16x16, 32x32, 64x64)

## Screenshots

### In `screenshots/` directory:
1. **screenshot-plan.png** - Plan screen showing trip form with destination, time, and calculate button
   - Dimensions: Recommend 540x1080 (9:18 aspect ratio for phone frame)
   - Shows the main planning interface

2. **screenshot-result.png** - Result screen showing calculated departure time and trip details
   - Dimensions: Recommend 540x1080
   - Shows confidence ring, countdown timer, and trip information

3. **screenshot-history.png** - Trip history screen showing past trips
   - Dimensions: Recommend 540x1080
   - Shows list of previous trips with confidence indicators

4. **screenshot-map.png** - Map screen showing route visualization
   - Dimensions: Recommend 540x1080
   - Shows the calculated route on a map

5. **screenshot-settings.png** (Optional) - Settings screen for favorites and preferences
   - Dimensions: Recommend 540x1080
   - Shows dark mode and home/work location settings

## How to Add Actual Assets

### For Screenshots:
1. Take screenshots directly from the Airylio mobile app on Android
2. Crop to proper dimensions (suggest 540x1080 for portrait phone frames)
3. Compress PNG files to optimize for web (target: < 200KB each)
4. Name files exactly as specified above

### For Favicon:
1. Export the Airylio app icon as ICO format
2. Create multiple sizes: 16x16, 32x32, 64x64 pixels
3. Name as `favicon.ico`

### Optimization Tips:
- Use TinyPNG or similar tool to compress screenshots
- Ensure screenshots are well-lit and show app features clearly
- Consider adding subtle shadows or framing in screenshots
- Keep all screenshots styled consistently (same theme mode)
